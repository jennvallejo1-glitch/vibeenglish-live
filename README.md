# 📘 VibeEnglish — Plataforma de Aprendizaje de Inglés (InglesPasoAPaso)

Plataforma interactiva de aprendizaje de inglés con arquitectura frontend completa (pantallas de bienvenida, registro, inicio de sesión, planes de suscripción, guía de 6 unidades con 36 lecciones, 3 niveles de inglés, manual de uso, laboratorio de audio, conversación, pronunciación, foro, progreso, logros y 3 temas visuales: Claro, Oscuro y Colorido).

## 🚀 Ejecución Rápida en Entorno Local

### 1. Clonar el repositorio privado
```bash
git clone https://github.com/jennvallejo1-glitch/InglesPasoAPaso.git
cd InglesPasoAPaso
```

### 2. Instalar dependencias (cuando se agreguen paquetes de backend)
```bash
npm install
```

### 3. Iniciar el servidor local en `http://localhost:3000`
```bash
npm start
```
*(O en Windows haciendo doble clic sobre `Iniciar VibeEnglish.bat`)*
